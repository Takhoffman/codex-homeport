# Code of Conduct

Be kind, direct, and useful.

This project follows the spirit of the Contributor Covenant: contributors should be treated with respect regardless of background, identity, experience level, or tool preferences.

Unacceptable behavior includes harassment, personal attacks, doxxing, sustained disruption, and intentionally unsafe guidance around local credentials or destructive filesystem actions.

Project maintainers may remove comments, close issues, or block participants who make the project less safe or welcoming.
