# v0.13.0

- Added GitHub Copilot subscription models to the Codex Desktop and CLI
  harnesses through the official Copilot SDK and the user's existing Copilot
  CLI login.
- Added dynamic discovery of the models entitled by the active Copilot plan,
  including `copilot-auto`, plus per-home Copilot routing controls, login help,
  provider status, and model-picker entries.
- Kept tool execution and approvals inside Codex while bridging streamed model
  output, function tools, free-form `apply_patch`, parallel tool calls, and
  tool-result continuations through Copilot.
- Hardened the bridge with exact per-request tool allowlists, built-in tool
  override handling, login-only authentication, stripped token and endpoint
  overrides, isolated transient session state, and no stored Copilot tokens.
- Bundled and licensed the pinned Copilot SDK for Apple Silicon and Intel
  runtimes, and added bridge regression tests to CI and release validation.
