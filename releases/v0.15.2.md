# v0.15.2

- Kept normal Codex Desktop instances running when Codex Multihome quits by
  launching each instance through an independent waiting LaunchServices broker.
- Applied the same independent lifetime to Codex Shim desktop instances used by
  per-home model routing.
- Preserved per-home profiles, browser testing mode, development flavor, and
  proxy settings across the detached launch path.
- Added regression coverage for persistent broker arguments and multi-instance
  PID discovery.
- Made normal and shim launches transactional: failed PID discovery now stops
  and reaps the waiting broker and removes only processes created by that launch.
- Added timeout, early-exit, ownership-transfer, late-arrival cleanup, and
  pre-existing-instance preservation tests for both desktop launch paths.
