# v0.8.0

- Added optional custom `CODEX_HOME` paths when creating clean-room, temporary, config-only, or cloned homes from the menu bar app, console, and CLI.
- Added editable saved-home paths after creation, including a move-files option for relocating an existing managed home and an adopt-existing-directory mode for prebuilt homes.
- Added `homeport path SLUG --path PATH [--move]` plus `--path` support on `homeport clone` and `homeport create`.
- Updated path changes to refresh clone-source and recent-launch references so saved homes keep pointing at the moved source.
