# v0.14.0

- The Main home can no longer be wired to the model-routing shim. The default
  `~/.codex` install always launches untouched, even if older state had routing
  enabled for it, and the Model Routing panel now explains this instead of
  offering the toggle. Shim providers such as GitHub Copilot remain available
  on clones, clean rooms, and temporary homes.
- App and Term launches no longer re-run `model use` while wiring the shim, so
  the model chosen in the picker stays active across launches.
- The menu panel is now vertically resizable with a persisted height.
- Provider sign-in rows report which Terminal the login flow opens in.
