# Codex Homeport v0.5.0

- Added live/dev channels so a development menu bar app can run beside the live app.
- Added `--channel live|dev` support for install, update, start, restart, autostart, configure, and uninstall flows.
- Added the `Codex Homeport Dev.app` bundle identity with bundle ID `com.takhoffman.codex-homeport.dev`.
- Added channel-specific Homeport state and managed-home directories for dev runs.
- Added bundle-embedded channel detection so the dev app keeps using dev state when launched normally.
- Updated updater installs to preserve the active channel.
- Documented the dev-channel workflow and added channel path coverage in tests.
