# v0.12.0

- Added an optional bundled mitmproxy runtime for per-home Codex Desktop and
  terminal traffic capture, including stable proxy and web-inspector ports.
- Added app and CLI controls to start, inspect, and stop proxy sessions, with
  per-home flow archives and explicit handling guidance for captured secrets.
- Added proxy-aware launch environment and Electron arguments, generated CA
  support, and launch-history badges showing shim and MITM usage.
- Improved home and recent-launch editing shortcuts, proxy controls in home
  details and settings, and menu layout behavior on shorter screens.
- Updated npm and app packaging to prepare and bundle the signed mitmproxy
  runtime for the host architecture while supporting universal releases.
