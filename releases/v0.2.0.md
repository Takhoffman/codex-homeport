# Codex Multihome v0.2.0

- Added `homeport version` and `homeport --version`.
- Added generated app bundle versions from `HomeportCore/AppVersion.swift`.
- Added a root `install.sh` for a git-backed Mac install into the Homeport application support directory.
- Updated `homeport update` to reinstall the app automatically when it is already installed.
- Updated `homeport update` to restart a running menu bar app after reinstalling unless `--no-restart` is passed.
- Documented the install, update, and semantic versioning strategy.
- Restored menu-bar copy templates and per-category copy checkboxes.
