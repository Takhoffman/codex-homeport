# Codex Multihome v0.6.0

- Added per-category clone policies so new homes can skip, copy, or symlink supported Codex home paths.
- Added clone source selection from Main or another managed home, plus CLI flags for `--source`, `--link-safe`, `--link-auth`, and `--link`.
- Added exact clone policy provenance, linked-home tags, and missing linked-target warnings.
- Added optional auth symlinking while keeping browser state, memories, and history copy-or-skip only.
- Fixed Main home favorite state on fresh installs by giving Main a stable identity.
- Polished the focused home detail screen with richer status, launch, auth, and manage controls.
