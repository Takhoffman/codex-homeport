# Codex Homeport v0.4.0

- Added proactive update checks from the menu bar app.
- Added menu bar and Settings red-dot badges when a newer npm version is available.
- Added a Settings updater card with Check Now, Update, Later, daily/weekly schedule, and automatic-install controls.
- Added background update installs through npm using the package root and `homeport update --with-app --no-restart`.
- Added updater state persistence, update logs, npm check timeouts, and duplicate-install suppression.
- Added `homeport configure` flags for updater preferences: `--update-checks`, `--update-interval`, and `--auto-install-updates`.
- Removed source UI mockups and current documentation references to them.
