# Codex Homeport v0.3.0

- Added npm package metadata for `npm install -g codex-homeport`.
- Added the npm `homeport` wrapper and postinstall Swift build.
- Updated install/update documentation to make npm the recommended Mac path.
- Replaced the menu bar app with a phone-style tabbed SwiftUI menu.
- Added Favorites, Recents, Homes, New Home, and Settings tabs.
- Added focused home detail views with Back/Edit controls.
- Added explicit `App` and `Term` launch buttons for launchable homes and recents.
