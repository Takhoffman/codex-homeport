# v0.10.0

- Bundled the cleaned Codex Shim runtime directly in Codex Multihome, removing
  the default dependency on an external checkout or user-installed executable.
- Added standalone offline Python runtimes for Apple Silicon and Intel Macs,
  including pinned shim dependencies, so model routing works without system
  Python or network access after installation.
- Kept the optional Shim executable setting as an explicit override for users
  who intentionally manage a separate runtime.
