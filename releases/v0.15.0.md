# v0.15.0

- Renamed the CLI executable from `homeport` to `codex-multihome` across SwiftPM,
  npm, source installers, documentation, diagnostics, and app update commands.
- Removed the legacy npm command aliases so new installations expose one clear
  executable: `codex-multihome`.
- Made source-based installs remove an older `~/bin/homeport` executable after
  installing `~/bin/codex-multihome`.
- Added `CODEX_MULTIHOME_*` environment-variable names while keeping legacy
  `HOMEPORT_*` fallbacks and existing state files compatible, so the command
  rename does not reset user data or break older automation.
