# Bundled mitmproxy runtime

Run `scripts/prepare-mitmproxy-runtime.sh` for the host architecture or pass
`--all` for a universal release. Generated runtime directories are ignored by
Git; release builds package the pinned, checksum-verified upstream app bundles.
